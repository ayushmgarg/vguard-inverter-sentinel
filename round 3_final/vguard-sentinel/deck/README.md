# Finale deck
`VGuard-Sentinel-Finale-Deck.pptx` (13 slides, 16×9) + PDF export — built on the reference deck's design system: charcoal `#27272B` / `#1B1B1E` ground, single yellow accent `#FFE14D`, body `#D7D4CC`, grey cards `#46464A`, olive note strips `#4D4000`, Raleway type, half-slide image panels, numbered hairline columns and a numbered timeline; V-Guard Big Idea Tech logo bottom-right.

- `make_assets.py` → `assets_dark/` (charts and flowcharts generated from the prototype code and artefacts in `../prototype/code/`, dark palette)
- `build_deck_ref.py` → the deck. Regenerate: `python3 make_assets.py && python3 build_deck_ref.py`
- `VGuard-Sentinel-Finale-Deck-light-v1.pptx` — the earlier light-theme version (kept for reference); `make_assets_light.py` / `build_deck.py` / `assets/` are its sources.
